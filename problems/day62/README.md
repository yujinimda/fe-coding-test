## 문제

쇼핑몰의 상품 설명에 포함된 괄호가 올바르게 짝지어져 있는지 확인하는 함수를 작성하세요. 괄호는 '(', ')', '{', '}', '[', ']'만 고려합니다.

## 코드

```typescript
// 상품 설명에 포함된 괄호 문자열
const productDescriptions = [
  "(상품 설명입니다)",
  "{상품 설명입니다}",
  "[상품 설명입니다]",
  "(상품 설명입니다}",
  "{상품 설명입니다]",
  "[상품 설명입니다)"
];

// TODO: 여기에 구현하세요
function isValidParentheses(description) {
}

// 각 상품 설명에 대해 괄호가 올바르게 매칭되는지 확인
productDescriptions.forEach(description => {
  console.log(isValidParentheses(description));
});
```

## 요구사항

1. '(', ')', '{', '}', '[', ']' 괄호만 고려합니다.
2. 스택 자료구조를 사용하여 괄호의 짝을 확인해야 합니다.
3. 모든 괄호가 올바르게 짝지어져 있으면 true, 그렇지 않으면 false를 반환합니다.
4. 빈 문자열은 true로 간주합니다.
